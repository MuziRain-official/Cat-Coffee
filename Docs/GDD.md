# 猫咪咖啡馆 (Cat Café) — 游戏设计文档 (GDD)

> 版本 v0.3 · 2026-09-21 · 状态：P2.5 空间化完成，P3 丰富度设计定稿（待实现）

## 1. 概述

| 项 | 内容 |

| 类型 | 模拟经营 / 休闲 |
| 视角 | 2D 正俯视（正交相机） |

## 2. 核心循环（三层嵌套）

```
【秒级·局内】
  顾客进店 → 落座自动点单 → 主角做咖啡(时机小游戏) → 装杯 → 上菜/放保温台 → 顾客用餐付费
                    ↑
              猫咪：喂食/铲屎/互动维持心情 + 抱到不同区域产生不同增益
                    ↑
              备餐：空档提前做咖啡放保温台，新鲜度随时间下降
【局级】开局准备 → 营业中(约6分钟) → 打烊结算 → 营业额−成本=利润
【长线】利润 → 声望 → 解锁新菜品/扩张店面/招员工/收养新猫 → 下一局更强
```

## 3. 核心操作：主角空间移动 + 制作小游戏

玩家控制**主角**在正俯视咖啡馆里移动，走到设备/猫前按键交互。

### 3.1 服务线（做咖啡赚钱）

```
顾客落座自动点单（头顶气泡显示「拿铁」+ 耐心条）
  ↓
主角走到【咖啡机】按 E → 萃取时机小游戏（详见 §3.3）
  ↓
小游戏结束 → 咖啡液留在咖啡机（品质锁定）→ 走到咖啡机按 E 取原料
  ↓
走到【装杯台】按 E → 装杯（即时）
  ↓
走到【保温台】按 E → 放入保温台备餐（可选）  OR  直接端去上菜
  ↓
走到【顾客座位】按 E → 上菜 → 顾客用餐 → 付费离开
```

### 3.2 猫咪线（经营猫咪，不只是喂）

```
猫咪三态（饱腹/清洁/心情）随时间下滑
  ↓ 走到猫前：E喂食 / Q铲屎 / R互动（多键）
  ↓ 走到猫前按 F → 抱猫（移动减速30%，不能做咖啡/上菜）
  ↓ 走到某猫垫按 F → 放下
猫垫决定增益区域（详见 §3.4），猫心情决定增益强度
```

### 3.3 制作小游戏：萃取时机条（核心手感）

走到咖啡机按 E，进入**时机条小游戏**：

- 一根指针在条上左右摆动（约 2-3 秒）
- 看准时机再按 E → 指针停在某区间
- **绿色=完美 / 黄色=良好 / 红色=勉强**（三档）

品质锁定后咖啡液留在咖啡机（保留"取原料"步骤）。**无失败，只有好坏**——做砸了也能卖，只是少赚。

| 品质 | 售价倍率 |
|------|---------|
| 完美 | ×1.3 |
| 良好 | ×1.0 |
| 勉强 | ×0.7 |

**关键取舍**：小游戏**替代**了原来的读条。萃取不再是"按 E 等 2.5 秒"，而是"停下来玩 2-3 秒小游戏"。多任务调度来自：萃取完的咖啡液留在机器可先去干别的、提前备餐。

### 3.4 猫咪区域增益（猫从"负担"变"策略"）

三个猫垫，猫放在哪个，哪个区域生效：

| 猫垫位置 | 增益 |
|---------|------|
| 吧台旁 | 萃取小游戏绿色区间**变宽 30%**（更好操作） |
| 座位区 | 顾客耐心下降**减速 25%** |
| 门口 | 顾客生成**加速 20%**（客流更旺） |

- **增益强度 = 猫心情**：心情 >70 全额、30~70 半额、<30 失效
- 抱猫（F）→ 走到猫垫（F）放下，**移动是成本**（抱猫减速 30%）

### 3.5 备餐 + 新鲜度（策略层）

保温台可放 **3 杯**成品咖啡。顾客来了直接从保温台拿（瞬间上菜）。

- **新鲜度**：咖啡放保温台后从 100 匀速降到 0（约 90 秒）
- **最终售价 = 基础价 × 品质(小游戏) × 新鲜度**
- 权衡：趁空档多备？备多放久变难喝；不备，高峰期手忙脚乱。

### 3.6 操作与交互键位

| 按键 | 动作 |
|------|------|
| WASD | 移动 |
| E | 交互（做咖啡/取原料/装杯/上菜/喂食/放保温台） |
| Q / R | 猫咪：铲屎 / 互动 |
| F | 抱猫 / 放猫 |
| 空格 | 暂停 |

### 3.7 架构：逻辑与表现分离

- **逻辑层**：GameFlow / Customer / CatState / Order / DayLedger 纯数据可测，不碰 GameObject。
- **表现层**：主角、设备、猫、顾客的空间实体 + 输入，负责"空间交互转成逻辑方法调用"。

## 4. 货币系统

- **金币**（局内）：顾客付费 = 基础价 × 品质 × 新鲜度。
- **声望**（长线）：`利润 × 转化率`，跨局持久，买永久解锁。

## 6. 场景布局（P3 重排）

```
         [门口] ←顾客从这里进
      座位  座位  座位
      座位  座位  座位       ← 6 座聚在上方，离门近
      [猫垫·座位区]
    [猫垫·吧台]      [猫垫·门口]
    咖啡机 装杯台 保温台      ← 吧台三件套紧挨着，做咖啡少跑路
         [主角出生]
```

**原则**：制作三件套（咖啡机/装杯台/保温台）抱团，高频动作少跑路；上菜"吧台→座位"短而均匀；三个猫垫在顺路位置。

## 7. 设计决策记录（已拍板）

| 决策 | 选择 | 理由 |
|------|------|------|
| 单局边界 | 一个营业日（约 6 分钟） | 边界清晰，局内外切换好实现 |
| 核心操作 | 主角空间移动 + 制作小游戏 | 移动+手感+策略三层乐趣 |
| 移动方式 | 键盘 WASD | 直观响应快 |
| 交互方式 | 靠近 + 按键(E/Q/R/F) | 有主动感不误触 |
| 视角 | 2D 正俯视（正交） | 坐标/碰撞最简 |
| 制作小游戏 | 萃取时机条，三档品质 | 无失败只有好坏，契合基调 |
| 小游戏与读条 | 小游戏替代读条 | 流程更清爽，保留取原料约束 |
| 品质分档 | 三档（完美/良好/勉强） | 反馈清晰 |
| 上菜目标 | 到顾客座位（或保温台） | 真实服务感 |
| 备餐系统 | 保温台 3 格 + 新鲜度 | 提前备餐 vs 现做的策略 |
| 猫咪改造 | 抱猫到猫垫 = 区域增益 | 猫从负担变策略 |
| 猫咪互动 | 多键 E喂食/Q铲屎/R互动 | 主动选择 |
| 顾客点单 | 自动点单 | 落座即出气泡 |
| 座位数 | 初始 6 座，可扩建 | 扩建归 P3 |
| 碰撞 | 可穿过猫/顾客；桌椅/设备/墙不可穿 | 动态不挡路，静态构成布局 |
| 长线经济 | 纯解锁制 | 最简单无破产压力 |
| 失败条件 | 无失败纯正向 | 只赚多赚少 |
| 营业日时长 | 6 分钟 | 休闲标准长度 |
| 整体紧张度 | 均衡 | 有调度压力不焦虑 |
| 美术音频 | AI 生成 + 风格锁 | 全 AI 闭环 |

## 8. 美术风格（P5 已定稿）

### 风格定位
**东方夜雀食堂式像素风 + 奶油复古色 + 无描边**

- 像素颗粒质感，复古温馨，参考《东方夜雀食堂》《Cafe Master Story》
- 奶油复古色调：奶油白、暖棕、淡橙、抹茶绿，低饱和、柔和
- 无描边，色块直接相接，柔和治愈
- 2D 正俯视，几何感清晰

### 风格锁（P5 生成所有图必须用这个统一 prompt 前缀）

```
pixel art, top-down view, cozy cat cafe, cream and warm brown retro palette,
soft low-saturation colors, no outline, clean shapes, warm cozy atmosphere,
game asset sprite
```

后续 `generate_image` 时，把具体物体描述接在此前缀之后，例如：
`...前缀... , a coffee machine on a counter, 48x48 pixel sprite`
