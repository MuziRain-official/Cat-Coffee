## 2. 核心循环（三层嵌套）

```
【秒级·局内】顾客进店 → 落座点单 → 玩家点击制作 → 点击上菜 → 顾客用餐 → 满意付费离开
                    ↑
              猫咪状态（饥饿/清洁/心情）← 玩家喂食/铲屎/互动
              └→ 状态好：顾客停留更久、消费更多；状态差：顾客流失
【局级】开局准备 → 营业中(约6分钟) → 打烊结算 → 营业额−成本=利润
【长线】利润 → 声望 → 解锁新菜品/扩张店面/招员工/收养新猫 → 下一局更强
```

## 3. 核心操作：固定工序制作（点击调度）

玩家在局内的操作是**两套"点按调度"**，争夺同一份注意力：

**服务线（做饮品赚钱）**
顾客进店落座 → 头顶冒出订单气泡 → 点击设备按**固定工序**制作 → 点击上菜 → 顾客用餐付费离开。

**猫咪线（维持增益，不做会掉收益）**
猫咪状态条（饥饿/清洁/心情）缓慢下滑 → 点击猫咪喂食/铲屎/互动 → 状态恢复 → 全店增益生效（顾客多待、多花）。

**张力来源**：服务线与猫咪线的拉扯——咖啡做不过来，猫还在饿，先救快流失的顾客，还是先喂猫保全局增益。

### 制作 = 固定工序，非自由合成

- **固定工序**：每杯饮品按**固定顺序**点 2-3 步，点对顺序即可，**无对错**（与"无失败纯正向"兼容）。
- **非自由合成**：不做"原料自由组合出配方"——那会引入配方记忆与"配错有代价"，与治愈基调冲突。
- **MVP 步数 = 2 步**：`制作 → 装杯`，两台设备。后续新饮品可扩展为 3 步（磨豆→冲泡→拉花）等。

```
拿铁（MVP，2 步）：
  1. 点咖啡机 → 萃取（短读条）
  2. 点组装台 → 装杯（即点即得）
  → 点击上菜
```

**深度来源**：多顾客的饮品卡在不同工序上，玩家需在设备间排队调度（A 在萃、B 该装杯、C 快等不及）。

## 4. 货币系统

- **金币**（局内）：顾客付费所得，仅本局有效，用于购买食材 / 临时道具。
- **声望**（长线）：`利润 → 按比例转声望`，跨局持久，用于购买永久解锁。

## 5. 系统清单

| # | 系统 | 说明 | 阶段 |
|---|------|------|------|
| 1 | 时间系统 | 营业日倒计时、加速/暂停 | P2 |
| 2 | 顾客系统 | 生成 + 状态机（进店→点单→等待→用餐→付费→离开） | P2 |
| 3 | 订单系统 | 菜单、制作、上菜 | P2 |
| 4 | 猫咪系统 | 饥饿/清洁/心情三态 + 互动，状态影响顾客 | P2 |

| 8 | 存档系统 | 长线进度持久化 | P3 |

## 6. MVP 范围（P2 竖切片，砍到最薄）

> **1 种咖啡 · 1 只猫 · 1 种顾客 · 营业日时间 · 制作+上菜 · 喂食+铲屎 · 结算+声望 · 极简 UI**

员工、多菜品、扩张、收养、存档，全部后移 P3。

## 7. 设计决策记录（已拍板）

| 决策 | 选择 | 理由 |
|------|------|------|
| 单局边界 | 一个营业日（约 6 分钟实时） | 边界清晰，局内外切换好实现，最适合竖切片 |
| 猫咪定位 | 特色 + 双向责任 | 喂食/铲屎换增益，最有灵魂 |
| 核心操作 | 点击调度（固定工序） | 逻辑简单、事件驱动，AI 好写好测 |
| 制作工序 | 固定工序，MVP 2 步（制作→装杯） | 兼容无失败，深度靠设备排队调度 |
| 长线经济 | 纯解锁制 | 最简单、无破产压力 |
| 失败条件 | 无失败，纯正向 | 只赚多赚少，情绪压力低 |
| 美术音频 | AI 生成 + 风格锁 | 全 AI 闭环 |

## 8. 美术风格（待 P5 定稿）

- 方向建议：治愈系扁平矢量 / 柔和粉彩，暖色调，圆润造型。
- **风格锁**：generate_image 时写死统一 prompt 前缀（具体措辞 P5 定），保证跨资源风格一致。

## 9. 后续方向（P3+ 扩展池，按优先级）

1. 新菜品解锁（咖啡/甜点，含制作时长差异）
2. 员工系统（自动上菜/清洁，减轻后期操作量）
3. 店面扩张（更多座位、更多猫位）
4. 收养新猫（每只独立状态 + 局外收集）
5. 顾客类型分化（偏好不同菜品的顾客）
