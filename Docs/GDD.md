# 猫咪咖啡馆 (Cat Café) — 游戏设计文档 (GDD)

> 版本 v0.1 · 2026-09-21 · 状态：P1 定稿（待用户最终确认后锁定）

## 1. 概述

| 项 | 内容 |
|----|------|
| 类型 | 模拟经营 / 休闲 |
| 视角 | 2D 俯视角 |

## 2. 核心循环（三层嵌套）

```
【秒级·局内】顾客进店 → 落座点单 → 玩家点击制作 → 点击上菜 → 顾客用餐 → 满意付费离开
                    ↑
              猫咪状态（饥饿/清洁/心情）← 玩家喂食/铲屎/互动
              └→ 状态好：顾客停留更久、消费更多；状态差：顾客流失
【局级】开局准备 → 营业中(约6分钟) → 打烊结算 → 营业额−成本=利润
【长线】利润 → 声望 → 解锁新菜品/扩张店面/招员工/收养新猫 → 下一局更强
```

## 3. 核心操作：主角空间移动 + 固定工序制作

玩家控制一个**主角**，在 2D 正俯视视角的咖啡馆里**移动**，走到设备/猫咪前**按交互键**触发操作。

**服务线（做饮品赚钱）**
顾客进店落座 → 头顶冒出订单气泡 → 主角走到咖啡机前按交互键「萃取」→ 走到前台「装杯」→ 走到出餐口「上菜」→ 顾客用餐付费离开。

**猫咪线（维持增益，不做会掉收益）**
猫咪状态条（饥饿/清洁/心情）缓慢下滑 → 主角走到猫咪身前按交互键「喂食/铲屎/互动」→ 状态恢复 → 全店增益生效（顾客多待、多花）。

**张力来源**：服务线与猫咪线的**空间拉扯**——咖啡要做、猫要喂，主角只有一个人，先跑哪边？移动本身成了决策成本。

### 操作与交互方式
- **移动**：键盘 WASD / 方向键。
- **交互**：靠近设备/猫后按交互键（E）触发。
- **视角**：2D 正俯视（正交相机），地面网格。
- **制作 = 固定工序**（非自由合成）：萃取 → 装杯 → 上菜，2 步（萃取读条 2.5s，装杯即时）。

### 架构：逻辑与表现分离（本方向的关键）
- **逻辑层（保留，纯数据可测）**：GameFlow / Customer / CatState / Order / DayLedger 继续做纯仿真，不碰 GameObject。
- **表现层（新增）**：主角、设备、猫、顾客的空间实体 + 移动/交互输入，负责「把空间交互转成逻辑方法调用」。
- 好处：逻辑仍可单元测试；表现层可独立迭代。

## 4. 货币系统

- **金币**（局内）：顾客付费所得，仅本局有效，用于购买食材 / 临时道具。
- **声望**（长线）：`利润 → 按比例转声望`，跨局持久，用于购买永久解锁。

## 7. 设计决策记录（已拍板）

| 决策 | 选择 | 理由 |
|------|------|------|
| 单局边界 | 一个营业日（约 6 分钟实时） | 边界清晰，局内外切换好实现，最适合竖切片 |
| 猫咪定位 | 特色 + 双向责任 | 喂食/铲屎换增益，最有灵魂 |
| 核心操作 | 主角空间移动 + 固定工序 | 走到设备/猫前按 E 交互，移动是决策成本 |
| 移动方式 | 键盘 WASD | 直观、响应快，主流俯视经营方案 |
| 交互方式 | 靠近 + 交互键(E) | 有主动感，不误触 |
| 视角 | 2D 正俯视（正交） | 坐标/碰撞最简，AI 开发友好 |
| 制作工序 | 固定工序，MVP 2 步（萃取→装杯→上菜） | 兼容无失败，深度靠空间调度 |
| 长线经济 | 纯解锁制 | 最简单、无破产压力 |
| 失败条件 | 无失败，纯正向 | 只赚多赚少，情绪压力低 |
| 营业日时长 | 6 分钟 | 小体量休闲标准长度 |
| 整体紧张度 | 均衡 | 有适度调度压力但不焦虑 |
| 美术音频 | AI 生成 + 风格锁 | 全 AI 闭环 |

## 8. 美术风格（待 P5 定稿）

- 方向建议：治愈系扁平矢量 / 柔和粉彩，暖色调，圆润造型。
- **风格锁**：generate_image 时写死统一 prompt 前缀（具体措辞 P5 定），保证跨资源风格一致。

## 9. 后续方向（P3+ 扩展池，按优先级）

1. 新菜品解锁（咖啡/甜点，含制作时长差异）
2. 员工系统（自动上菜/清洁，减轻后期操作量）
3. 店面扩张（更多座位、更多猫位）
4. 收养新猫（每只独立状态 + 局外收集）
5. 顾客类型分化（偏好不同菜品的顾客）
